# Руководство по внесению вклада (Contributing Guide)

Мы рады, что вы хотите внести свой вклад в развитие фреймворка Imhotep!

Ниже приведены инструкции, которые помогут вам начать работу и сделать процесс взаимодействия максимально эффективным.

## С чего начать?
- Обсудите вашу идею в Issue или [Telegram](https://t.me/+iEb2fWMBGYk3ZWYy) перед началом работы.
- Убедитесь, что никто уже не работает над этой задачей.

## Как сообщить об ошибке

Если вы нашли ошибку, пожалуйста, создайте **Issue** в соответствующем репозитории.
В описании ошибки укажите:
1. Версию фреймворка.
2. Версию PHP.
3. Шаги для воспроизведения ошибки.
4. Ожидаемое и фактическое поведение.

Если вы обнаружили уязвимость безопасности, пожалуйста, **не создавайте публичный Issue**. Вместо этого напишите нам на почту: imhotep.php@gmail.com.

Также вы можете обсудить ошибки и задать вопросы в нашем Telegram-чате: [@imhotep_php](https://t.me/+iEb2fWMBGYk3ZWYy)

## Предложение улучшений

Если у вас есть идеи по улучшению фреймворка, вы также можете создать Issue с меткой `enhancement` или `proposal`. Подробно опишите вашу идею и какую проблему она решает.

## Процесс разработки (Pull Requests)

1. **Форкните репозиторий** и клонируйте его к себе.
2. Создайте новую ветку для ваших изменений: `git checkout -b feature/my-new-feature`.
3. Внесите изменения. Пожалуйста, следуйте существующему стилю кода (PSR-12).
4. **Запустите тесты**, чтобы убедиться, что ничего не сломалось.
5. Закоммитьте изменения: `git commit -m 'Add some feature'`.
6. Отправьте изменения в ваш форк: `git push origin feature/my-new-feature`.
7. Создайте **Pull Request** в основной репозиторий.

## Стандарты кода

* Мы придерживаемся стандарта PSR-12.
* Используйте типизацию (Type Hints) везде, где это возможно.
* Добавляйте PHPDoc для классов и методов.

## Коммиты

Используйте осмысленные сообщения коммитов на английском языке. Пример:

- `feat(auth): add middleware`
- `fix(session): resolve expiration bug`
- `refactor(cache): complete restructuring`

## Тестирование

Перед отправкой изменений обязательно запустите тесты.
Для запуска тестов используйте PHPUnit:

```bash
# Запуск всех тестов
vendor/bin/phpunit

# Запуск конкретного теста:
vendor/bin/phpunit --filter TestClassName

# Проверка покрытия кода:
vendor/bin/phpunit --coverage-html coverage
```
